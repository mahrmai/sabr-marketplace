# SABR Marketplace — Multi-Vendor Commerce Platform

A multi-vendor online marketplace that lets the general public and small vendors **sell, auction, buy, and rent** items in one place — built as a hardened, self-service WordPress/WooCommerce platform with a custom marketplace theme.

🔗 **Live concept:** sabr.pk

## The problem
Ordinary people and small vendors need a low-barrier way to trade goods online — not just fixed-price sale, but also auctions and rentals — without building or operating their own storefront, and without the security and spam problems that plague typical WordPress commerce sites.

## What it does
A custom marketplace theme (v1.1.0) on top of WooCommerce + Dokan multi-vendor, supporting **four listing modes**:

- 🛒 **Sale** — standard fixed-price listings
- 🔨 **Auction** — competitive bidding
- 🤝 **Buy** — buyer requests / offers
- 📅 **Rent** — time-bounded rental listings

### Platform features
- **OTP-based registration** and **two-step login** for verified, secure sign-up
- **Members-only access** controls
- **Vendor self-service** — store setup, listings, and profile management
- **Owner analytics dashboard** for marketplace oversight
- **Security hardening** built into the theme (dedicated SABR Security settings panel)
- Multi-currency support and standard commerce pages (About, FAQ, Privacy, Shipping, COD)

## Role
End-to-end delivery: platform architecture, custom theme development, secure vendor onboarding flow, data migration tooling, deployment guide, and a security review that hardened the site against the malware issues common to legacy WordPress installs.

## Tech
WordPress · WooCommerce · Dokan (multi-vendor) · custom PHP theme · OTP/SMS verification · phpMyAdmin/MySQL · cPanel deployment.

## Repository scope
This repository documents the **marketplace platform and custom theme**. Operational data — real users, catalogues, and infrastructure details — is intentionally excluded.
